# Fallen: polish director gate (feel + sound)

Judged from code and docs only; nothing was played. Unverified: the ocean sound (soundscape not read), real quality of the generated groans, current engine_soft values, zombie animation.

## Findings

**Blocker**
1. No melee swing animation found. grep for "melee" in character_model.gd, gear_rig.gd and gear_sway.gd returns nothing, and the `melee_winding` meta is read only in melee.gd:54,70,80,187. So the player's swing and the zombie's 0.55 s lunge windup (melee.gd:36) have no visible telegraph (unverified: it could live in a file I did not search). Anticipation-to-impact is the core of melee feel. Fix: knife light = 120 ms draw-back ease-in, 60 ms strike ease-out, 100 ms recover; heavy = 450 ms draw with a body lean; zombie lunge: head and arm rise across the 550 ms. Effort M-L.

**Major**
2. One generic hit sound. melee.gd:206-212 reuses the gun's impact_body (synth, 0.16 s, -6 dB) for every blow: blade, blunt, head, kill. No swing whoosh or whiff; block, parry and dodge give only text (melee.gd:114-129 via _note). Fix: whoosh 80 ms at windup start; blade-flesh and blunt-flesh sounds; head hit gets a heavier layer; parry = metal ring plus 50 ms hit-stop. Effort M.
3. Hit shake is a constant HIT_SHAKE 0.18 (melee.gd:203) using Contractor's random per-frame offset (player_input.gd:542-544): a light stab and a heavy feel the same. Make it scale with energy, directional, 90 ms ease-out. Only the attacker is shaken (melee.gd:211); I found no shake or flash when the player is bitten. Effort S.
4. Input latency: a light swing is sent on button release (melee_input.gd:40-42), then a 0.22 s windup (knife, items.json:365), then a host RPC with no local prediction. Heavy needs a 0.35 s hold (melee_weapons.gd:18) plus 0.45 s windup. Consider firing on press and deciding heavy during the windup. Effort M.
5. Zombie audio is new and thin: _voice/_moan (zombie_ai.gd:415-431) play one groan/scream pair every 9-24 s (MOAN_GAP_S, line 117), generated by FallenSynth. Missing: lunge grunt, hit/pain reaction, death sound, dragging steps, variation per kind. Real recordings would help most. Effort M-L.
6. Engine too loud: the handoff says engine_soft went 160 to 120 m and unit_size 8 to 4, and dead vehicles are silenced. I did not re-check the values or hear it; B2928 is "not playtested" (handoff).

**Minor**
7. survival_audio.md: no voice clips rendered (everything is subtitles), music cues are placeholder tunes, thunder, wet steps and indoor reverb are not built.
8. Melee numbers are marked Proposed with no playtest evidence (UNDEAD_BODY_PTS_PER_J 0.02, HIT_STAGGER_S 0.6, BODY_REACH_M 0.45; melee_weapons.gd:25-34).
9. A stagger that cancels a lunge (melee.gd:183-189) has no recoil pose in the code I read; add a 200 ms hit-reaction so the cancel is readable.
10. Ocean sound at an inland farm getting louder: not investigated (handoff: "not looked at"). Cause unknown.

## What's missing / not done yet
- Swing, block and hit animation; windup telegraph.
- A differentiated melee sound set, including whiff, block, parry, dodge.
- Real zombie and ambience recordings; rendered voices; real music.
- Damage-received feedback for the player.
- Mix levels unmeasured; the playtest bugs (engine, ocean) unconfirmed in game.
